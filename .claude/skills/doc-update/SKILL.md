# Doc update

## Update order
1. `docs/IMPLEMENTATION_STATUS.md`
2. `docs/REQUIREMENTS_DELTA.md`
3. `docs/STRATEGY_SPECS.md` if strategy rules changed
4. `SELF_LEARNING.md` if a mistake should be remembered

## Rules
- write deltas, not restatements
- prefer tables and key:value format
- keep `CLAUDE.md` short and stable
